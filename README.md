### 升级说明

1. 本固件仅适用于 **BE12 Pro** 型号。升级前请确认您的无线路由器型号。
2. **本地升级：**解压下载的升级压缩包，登录无线路由器管理界面，依次点击“更多功能” > “系统管理” > “软件升级” > “本地升级”，选择解压得到的 `.bin` 文件，再点击“立即升级”。
3. **在线升级：**如果检测到新版本，可选择“在线升级”。路由器联网后会自动检测新版本；检测到后点击“立即升级”，并等待升级完成。
4. 升级过程中切勿断电，否则可能导致无线路由器损坏。

### Upgrade Instructions

1. This firmware is only for the **BE12 Pro**. Confirm your router model before upgrading.
2. **Local upgrade:** Extract the downloaded firmware archive and sign in to the router's administration interface. Go to **More Functions** > **System Management** > **Software Upgrade** > **Local Upgrade**, select the extracted `.bin` file, and click **Upgrade Now**.
3. **Online upgrade:** If a newer version is available, select **Online Upgrade**. While connected to the internet, the router will automatically check for a new version. If one is found, click **Upgrade Now** and wait for the upgrade to complete.
4. Do not disconnect the router from power during the upgrade. Doing so may damage the router.
